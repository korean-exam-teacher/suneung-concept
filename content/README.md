# 내용 파일 작성 규칙

`content/` 폴더의 JSON 파일 하나가 책의 한 장(章)입니다. 파일 이름 앞 숫자 순서대로 실립니다.
고친 뒤에는 `tools/build.ps1`을 실행하면 웹(`docs/`)과 책(`book/`)이 함께 다시 만들어집니다.

## 장 파일 구조

```json
{
  "part": "언어(문법)",          // 부: 언어(문법) | 문학 | 독서 | 화법·작문·매체
  "chapter": "음운",            // 장 이름
  "id": "ph",                   // 장 id (영문 소문자)
  "intro": "장 첫머리 안내 문단",
  "concepts": [ 개념, 개념, ... ]
}
```

## 개념 구조

```json
{
  "id": "ph-nasal",             // 장 id로 시작하는 고유 id
  "title": "비음화",
  "level": "핵심",              // 핵심 | 심화
  "summary": "한두 문장 요약",
  "body": [ 블록, ... ],
  "examples": [ { "ex": "국물 → [궁물]", "note": "설명" } ],
  "traps": [ "자주 틀리는 점" ],
  "kichul": {
    "groups": ["음운·음운 변동"],  // 문제은행의 유형묶음(비우면 갈래 전체)
    "areas": ["문법"],            // 문제은행의 유형갈래: 문법·매체·화법·작문·독서·문학
    "any": ["비음화"],            // 발문·<보기>·선지에 이 낱말 중 하나라도 있어야 함
    "max": 6,                     // 최대 문항 수
    "items": []                   // 꼭 넣을 문항 키(예: "2024-11||언어와 매체||35")
  }
}
```

## 블록 종류

- `{"p": "문단"}`
- `{"h": "소제목"}`
- `{"list": ["항목", "항목"]}`
- `{"table": {"head": ["열1","열2"], "rows": [["가","나"]]}}`
- `{"box": "핵심 정리 문장", "title": "상자 제목(선택)"}`

글자 안에서 `**굵게**`를 쓸 수 있습니다. 발음은 `[궁물]`처럼 대괄호로 적습니다.
